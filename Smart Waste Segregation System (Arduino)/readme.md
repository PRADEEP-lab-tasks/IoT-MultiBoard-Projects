
# ♻️ Smart Waste Segregation System (Arduino)

This project uses **Arduino**, an **Ultrasonic sensor**, a **Soil Moisture sensor**, and a **Servo motor** to automatically classify waste as **Wet** or **Dry**.  
The system detects the presence of waste using an ultrasonic sensor, measures its moisture content, and then directs it into the appropriate bin using a servo motor.

---

## 📌 Features
- Detects waste using an **Ultrasonic sensor**.
- Measures moisture content with a **Soil Moisture sensor**.
- Classifies waste as **Wet** or **Dry**.
- Uses a **Servo motor** to direct waste into the correct bin.
- Serial monitor displays real-time humidity and distance readings.

---

## 🛠️ Hardware Requirements
- Arduino Uno / Nano / Mega
- Ultrasonic Sensor (HC-SR04)
- Soil Moisture Sensor
- Servo Motor (SG90 or similar)
- Jumper wires
- Breadboard
- Power supply
