
# 🏠 Home Automation with ESP8266 & Blynk

This project demonstrates a simple **IoT-based home automation system** using an **ESP8266 NodeMCU** and the **Blynk platform**.  
It allows you to control a relay (connected to appliances like lights or fans) directly from your smartphone via the Blynk app.

---

## 📌 Features
- Control appliances remotely using the Blynk mobile app.
- Uses Wi-Fi connectivity for seamless operation.
- Simple and lightweight code for beginners in IoT.
- Relay control mapped to **Virtual Pin V0** in Blynk.

---

## 🛠️ Hardware Requirements
- ESP8266 NodeMCU
- Relay Module (connected to GPIO5 → D1 pin)
- Smartphone with Blynk App installed
- Wi-Fi connection
